# FORLOAD КП Generator

Приложение для автоматизации создания коммерческих предложений (КП) для отдела продаж спецтехники.

## О проекте

Программа автоматизирует подготовку коммерческих предложений на основе уже готовых шаблонов КП.

Менеджеру не нужно вручную редактировать Word-документ, рассчитывать стоимость дополнительного навесного оборудования и добавлять фотографии.

Достаточно выбрать готовое КП, указать компанию и при необходимости выбрать дополнительное навесное оборудование.

## Возможности

- Выбор готового шаблона коммерческого предложения
- Автоматическое определение базовой стоимости выбранного КП
- Выбор дополнительного навесного оборудования
- Автоматический расчёт итоговой стоимости
- Ручной ввод итоговой стоимости
- Добавление названия компании в КП
- Автоматическое добавление выбранного навесного оборудования
- Формирование таблицы с навесным оборудованием
- Автоматическое добавление фотографий оборудования
- Создание готового документа `.docx`
- Автоматическое открытие созданного коммерческого предложения
- Работа в виде отдельного `.exe` приложения

## Как работает

1. Менеджер выбирает готовое КП.
2. Программа определяет стоимость выбранной модели.
3. Менеджер вводит название компании.
4. При необходимости выбирает дополнительное навесное оборудование.
5. Программа рассчитывает итоговую стоимость.
6. В выбранный шаблон добавляется информация о компании.
7. Формируется таблица дополнительного оборудования с фотографиями.
8. Создаётся готовое коммерческое предложение в формате `.docx`.
